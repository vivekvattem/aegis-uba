# Attack Taxonomy

- `brute_force`: high failure count and short-lived authentication attempts.
- `impossible_travel`: geographically distant consecutive activity within implausible elapsed time.
- `credential_stuffing`: shared hostile source IP failing against multiple entities.
- `lateral_movement`: unusual sensitive-resource access and privileged command traversal.
- `device_spoofing`: entity activity from an unseen spoofed device fingerprint.
- `low_and_slow_exfiltration`: elevated upload volume during ordinary-looking sessions.
- `insider_drift`: gradual expansion toward sensitive access, retained for false-positive analysis.
